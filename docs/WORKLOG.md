# Журнал работ

## 2026-10-17 — этап 3: DLL со статическим CRT

- **План:** `docs/PLAN.md`. Вид DLL выбрал владелец: статический CRT, без VC++ Redistributable.
  Готового триплета для «DLL + `/MT`» в vcpkg нет, поэтому свои оверлейные. OpenSSL в shared-сборке
  сам ставит `/MD`, но `CFLAGS` vcpkg с `-MT` идут в командной строке позже и побеждают.
  У каждой такой DLL свой CRT: `FILE*` приложения доходит до OpenSSL только через `applink.c`
  (`NOTES-WINDOWS.md`; uplink есть у всех трёх VC-целей). Ревизия сборки в теге нужна потому,
  что релиз версии порта 3.6.5#2 уже есть, а пропуск существующего релиза оставлять нужно.
- **Сделано:** оверлейные триплеты, линковка как ось матрицы, `run.ps1 -Linkage`, правки
  `smoke.c`, ревизия в теге. Прогон зелёный, релиз `r2` проверен (`docs/STATUS.md`).
- **Дальше:** владелец попросил, чтобы проверки не ждали всю матрицу сборок, — `docs/PLAN.md`.
