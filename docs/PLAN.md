# План — этап 2: smoke-тесты и релиз

Цель этапа — из `docs/ROADMAP.md`: отдельные джобы проверяют собранные библиотеки на раннере
своей архитектуры; после зелёных тестов CI публикует релиз с версией и хешами OpenSSL.

- [ ] `smoke/smoke.c`: версия библиотеки совпадает с заголовками; тестовый вектор SHA-256;
      AES-256-GCM туда и обратно; TLS 1.3 рукопожатие клиента и сервера через BIO-пару.
- [ ] `smoke/run.ps1`: сборка `cl` с `/MT` / `/MTd` против артефакта, проверка архитектуры
      exe и отсутствия несистемных DLL, запуск.
- [ ] `.github/workflows/build.yml` → `ci.yml`: джобы `smoke` — 3 архитектуры × Debug/Release,
      x86 и x64 на `windows-2025`, arm64 на `windows-11-arm`.
- [ ] Джоба `release`: на `main` после зелёных `smoke`, если релиза этой версии порта ещё нет.
      Тег `openssl-<версия>-port<N>`. В заметках — версия, тег и коммит исходников, SHA512
      архива исходников из SBOM vcpkg, версия порта, `builtin-baseline`, SHA-256 архивов.
      Ассеты — zip на триплет и `SHA256SUMS`.
- [ ] Прогон CI зелёный, релиз создан, его содержимое проверено.
- [ ] `CLAUDE.md` (карта, решения, деплой), `docs/STATUS.md`.
